# Retro Desk Display

Create a single-page React portfolio interface that mimics a retro beige CRT monitor setup on a clean desk background.

The Screen:

The central dark-gray area (the monitor screen) displays the large typography statement: 'DESIGN PORTFOLIO' (small), 'how i ORGANIZE' (neon green, serif font), and 'projects, content, client work' (white, sans-serif).

Include a subtle retro CRT scanline overlay effect.

A neon green pill button at the bottom reads 'SCROLL TO EXPLORE'.

The Sticky Notes (Navigation):

Arranged organically around the monitor are virtual, colorful sticky notes (blue, yellow, pink), acting as project categories.

The positions must mirror the generated image (image_1.png).

Each sticky note has gentle hover lift effects and links to a specific project modal or section.

Aesthetic details:

The text uses clean sans-serif and distinct editorial serif fonts.

Minimalist, high-end editorial feel.
